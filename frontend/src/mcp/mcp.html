Authentication and network access

Without a Mongoose Studio API key, the MCP endpoint uses the deployment's bindIp restrictions. By default, this means an MCP client can only connect from localhost.

With an API key, MCP clients such as Claude and ChatGPT connect through OAuth. You will be prompted to sign in to Mongoose Studio and approve the connection before the client receives access.

Permissions

When an API key is configured, MCP access is scoped to the signed-in user's workspace permissions. During authorization, the user can explicitly grant fewer permissions, such as read-only access or a lower execution time limit. An MCP connection can never receive more access than that user already has.

Supported operations

The MCP server supports database CRUD operations, dashboards, and script creation. It does not execute standalone scripts directly.

An MCP client can create a script and return a Mongoose Studio URL. A person can then open that URL, review or edit the code, and choose whether to dry run or execute it.
